# PhilipBlunk.com v2

Next.js / TypeScript / Tailwind starter for the new personal site.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- Dark mode is the default.
- Light mode is available from the moon/sun toggle and saved in localStorage.
- Work / About / Contact are single-page anchor links.
- The supplied Phil photo and TulHive screenshot are used directly from `/public/images`.
- Replace the placeholder LinkedIn URL and contact email before launch.
- `View project` is currently a placeholder for a future TulHive case-study route.
